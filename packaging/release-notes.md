Kova's first Windows preview: a native Rust/Slint file manager with tabbed
browsing, Windows Shell menus, drive overview, file thumbnails and an image,
text and PDF preview pane. Animated GIF, WebP and APNG play inside the preview.

## Download

- **Setup EXE:** installs for your Windows account, adds a Start menu shortcut
  and offers a desktop shortcut. Includes an uninstaller.
- **ZIP:** extract all files together and start **Kova.exe**.
- **SHA256SUMS.txt:** checksums for both downloads.

Requires Windows 10 version 1809 or later, or Windows 11, on x64. Visual C++
runtime files are included; Rust and Visual Studio are not needed.

This is an early, unsigned preview. The current app uses German navigation
labels. Folder integration is optional; global search, drag & drop and split
panes are not included yet. See the repository's documentation for preview
format limits and verification notes.
