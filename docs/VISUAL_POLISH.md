# Visual refinement

UI-only follow-up to the product audit: folder glyphs and larger close controls
in tabs, a single navigation-button surface, clearer text hierarchy, denser drive
cards, refined column widths and outlined selections that reflect list focus.
No file-operation, navigation or native Shell code changed.

The real release application was checked at 1140x780 and 780x550, including tab
creation/switching, address navigation, selection and opening/cancelling the New
Folder dialog. Both sizes retain readable controls and working scroll areas.
